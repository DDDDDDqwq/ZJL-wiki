- **1**

很久很久以前，种植园里有一对苦命鸳鸯：$\mathop{\textup{依里托托}}\limits^{Z\ \ J\ \ L}$与$\mathop{\textup{替罪羊}}\limits^{T\ \ Z\ \ Y}$。依里托托是一个尼格，每天都要在农场主的鞭笞下 work。替罪羊是一颗草莓，通了灵性有了思维，依里托托可怜他，于是把他留在了枝头上。

「原来，草莓也可以这么美丽吗！」

于是舍敞与替罪羊喜结连理。有了身份与地位的替罪羊每天都享受着舍敞搜刮来的财富，用着最潮的玩具、看着上好的川剧，渐渐淡忘了依里托托。当他们再次在种植园里相遇时，可怜的依里托托向替罪羊央求着川剧资源，但替罪羊却只是扭过头去：

「你什么$\color{brown}{肤色}$我什么$\color{red}{颜色}$？**Go work！**」

依里托托只好沮丧地离开。回想起往日种种，他不禁落泪。失去了替罪羊，依里托托只好与家里的猫（娘）姗姆一起过着贫苦的日子。

- **2**

「可琳，可琳，请关门！」

石门缓缓关闭。大盗们提了提裤子，装作无事发生地离开了。

确认大盗们走完后，依里托托才敢从树后出来。他咽了咽口水：石门里面究竟有什么激动人心的东西，能让大盗们都面红耳赤、精疲力竭地离开？他悄悄溜到了巨石前：

「可琳，可琳，请开门！」

巨石果然打开了。依里托托走进石门，里面的场景让他惊诧不已：四十台电脑闪烁着微弱的光芒，桌面上是五颜六色的$\mathop{\textup{旮旯给木}}\limits^{Galgame}$快捷方式，每台电脑上都有不同的种类：纯爱向，后宫向，校园向，萝莉向，母子向，BL向，福瑞向，猎奇向……琳琅满目，应有尽有。依里托托心里一阵狂喜，连忙摸出了口袋里伤痕累累的 U 盘开始拷贝。直到把自己 9.1 GB 的硬盘装得一字节都不剩了，他才心满意足地离开。

- **3**

- **5**

「可琳，可琳，请开门！」替罪羊在巨石前大喊。
